# План разработки проекта к ДЭ (Упрощенный)

Цель: Создать легкое и читаемое WPF-приложение для подготовки к ДЭ.
Акцент: Реализация функционала (Backend-логика, работа с данными) с использованием тестовых данных.

## Этапы:

1. **Подготовка окружения**
   - Создать структуру проекта.
   - Подключить основные библиотеки (если нужны).

2. **Модели данных (Mock Data)**
   - Создать классы сущностей (например, `Product`, `Order`, `User`).
   - Реализовать статический сервис или класс для генерации тестовых данных (по аналогии с `TemplateFor_SalesBoots`).

3. **Базовая логика (Core/Services)**
   - Реализовать класс `Core` (как в примерах) для управления навигацией и данными.
   - Добавить вспомогательные сервисы (ImageHelper, MessageHelper).

4. **UI - Навигация и Страницы**
   - Настроить `MainWindow` с `Frame` для навигации.
   - Реализовать страницы:
     - Авторизация (`AuthPage`).
     - Список записей/продуктов (`ListPage`).
     - Добавление/Редактирование (`AddEditPage`).

5. **Реализация функционала**
   - Отображение списка данных (Binding).
   - Поиск и фильтрация.
   - Добавление и удаление записей.

6. **Тестирование**
   - Проверка работы функционала на тестовых данных.

---
*Примечание: Модули 1 (БД) и 5 (диаграммы) пропускаем.*
